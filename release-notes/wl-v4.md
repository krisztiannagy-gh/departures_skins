### Smaller font files

- The font files store each pixel row as a number instead of a "0101" string: **15 KB less** on the box (street 19.7 → 7.6 KB, U-Bahn 4.5 → 1.7 KB).
- Nothing changes on the board: every character is pixel-for-pixel the same.

The box updates the skin by itself (when the Vienna skin is installed).
